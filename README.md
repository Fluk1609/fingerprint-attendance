# ระบบเช็คชื่อด้วยลายนิ้วมือ (มหาวิทยาลัย)

เว็บแอปสำหรับบันทึกวันเวลาที่นักศึกษา/บุคลากรสแกนลายนิ้วมือ พร้อมออกรายงานสรุปเป็นไฟล์ Excel
ออกแบบมาให้ **รันบนเครื่องเดียวกับที่ต่อเครื่องสแกนลายนิ้วมือ** (จุดเช็คชื่อจุดเดียว)

## โครงสร้างไฟล์

```
fingerprint-attendance/
├── app.py            # เว็บแอป Flask หลัก (หน้าเว็บ + API)
├── database.py        # จัดการฐานข้อมูล SQLite (users, scan_logs)
├── report.py           # สร้างไฟล์ Excel สรุปผล
├── scanner.py          # สคริปต์แยก อ่านค่าจากเครื่องสแกน แล้วส่งเข้าเว็บ
├── requirements.txt
├── templates/           # หน้าเว็บ (Jinja2)
└── static/               # CSS / JS
```

## วิธีติดตั้ง

```bash
cd fingerprint-attendance
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## วิธีรัน

เปิด 2 หน้าต่าง terminal:

**1) รันเว็บแอป**
```bash
python app.py
```
แล้วเข้า `http://127.0.0.1:5000` ในเบราว์เซอร์

**2) รันสคริปต์เชื่อมต่อเครื่องสแกน**
```bash
python scanner.py
```
ตอนนี้ `scanner.py` ใช้ `MockScanner` (โหมดจำลอง) ให้พิมพ์รหัสลายนิ้วมือทางคีย์บอร์ดแทนการวางนิ้วจริง
เพื่อทดสอบระบบทั้งหมดได้ทันทีโดยยังไม่ต้องมีเครื่องจริง

## เชื่อมต่อกับเครื่องสแกนลายนิ้วมือจริง

เนื่องจากยังไม่ทราบยี่ห้อ/รุ่นเครื่องที่แน่ชัด ไฟล์ `scanner.py` ถูกออกแบบเป็นโครงกลาง (adapter pattern)
ที่แยกส่วน "อ่านค่าจากเครื่องสแกน" ออกจากเว็บแอปโดยสมบูรณ์ ทำให้ **ไม่ต้องแก้ฐานข้อมูลหรือเว็บเลย**
เมื่อทราบรุ่นเครื่องแล้ว ให้ทำตามขั้นตอนนี้:

1. ติดตั้งไลบรารี Python สำหรับ SDK ของเครื่องนั้น เช่น
   - ZKTeco (ZK4500 / ZK9500) → `pip install pyzkfp`
   - DigitalPersona / HID → ใช้ DigitalPersona SDK ผ่าน `ctypes` เรียก DLL ที่มากับ SDK
   - ยี่ห้ออื่น → ดูเอกสาร SDK ของผู้ผลิตเครื่อง (มักมีตัวอย่างภาษา Python หรือ C++/C# ที่แปลงได้)
2. เปิดไฟล์ `scanner.py` เขียน class ใหม่สืบทอดจาก `FingerprintScanner`
   (มีตัวอย่างโครงร่างคอมเมนต์ไว้ให้ในไฟล์แล้ว สำหรับ ZKTeco และ DigitalPersona)
3. implement 3 เมธอด: `connect()`, `capture_and_identify()`, `disconnect()`
4. แก้บรรทัดใน `main()` จาก `MockScanner()` เป็นคลาสใหม่ที่เขียน
5. รัน `python scanner.py` ได้ตามปกติ ระบบเว็บจะรับข้อมูลเหมือนเดิมทุกอย่าง

> **สำคัญ**: ก่อนใช้งานจริง ต้องมีขั้นตอน "ลงทะเบียนลายนิ้วมือ" ผ่านโปรแกรมของ SDK เครื่องนั้นก่อน
> เพื่อให้ได้ `fingerprint_id` มาผูกกับชื่อ-นามสกุลในหน้า "จัดการผู้ใช้" ของเว็บนี้

## ฟีเจอร์หลัก

- **เก็บวันเวลาที่สแกน**: ทุกครั้งที่สแกนสำเร็จ ระบบจะบันทึก timestamp ลง SQLite อัตโนมัติ
  พร้อมจับคู่กับชื่อผู้ใช้ (ถ้าเคยลงทะเบียนไว้) แสดงผลแบบเรียลไทม์ที่หน้าแดชบอร์ด
- **รายงานสรุป Excel**: หน้า "รายงาน" เลือกช่วงวันที่ (และเลือกเฉพาะบุคคลได้) แล้วกดดาวน์โหลด
  จะได้ไฟล์ `.xlsx` 2 ชีต คือสรุปจำนวนครั้งต่อคน และรายละเอียดการสแกนทั้งหมด

## หมายเหตุด้านความปลอดภัย/การใช้งานจริง

- เปลี่ยนค่า `app.secret_key` ใน `app.py` ก่อนใช้งานจริง
- ข้อมูลลายนิ้วมือเป็นข้อมูลชีวมิติ (biometric) ควรตรวจสอบนโยบาย PDPA ของมหาวิทยาลัยเรื่องการเก็บ/ยินยอมให้ถูกต้อง
- ปัจจุบันไม่มีระบบ login แยกสิทธิ์ผู้ดูแล — ถ้าจะใช้งานจริงในมหาวิทยาลัยควรเพิ่มระบบยืนยันตัวตนสำหรับหน้า "จัดการผู้ใช้" และ "รายงาน"
