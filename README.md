# ระบบเช็คชื่อด้วยลายนิ้วมือ (Fingerprint Attendance System)

เว็บแอปพลิเคชันสำหรับบันทึกวันและเวลาที่นักศึกษา/บุคลากรสแกนลายนิ้วมือ พร้อมแสดงประวัติการสแกนและส่งออกรายงาน Excel พัฒนาด้วย Flask และ Supabase โดยเชื่อมต่อเครื่องสแกนลายนิ้วมือ ZKTeco ZK9500 ผ่าน USB

ระบบออกแบบมาสำหรับจุดเช็กชื่อที่ใช้คอมพิวเตอร์และเครื่องสแกนเพียงเครื่องเดียว

## ฟีเจอร์หลัก

- **Dashboard:** แสดงรายการสแกนล่าสุด
- **จัดการผู้ใช้:** จัดการข้อมูลนักศึกษา/บุคลากรและผูกกับ `fingerprint_id`
- **ลงทะเบียนลายนิ้วมือ:** เชื่อมต่อกับเครื่องสแกนผ่าน SDK เพื่อสร้างข้อมูลลายนิ้วมือ
- **บันทึกการเช็กชื่อ:** บันทึกเวลาและจับคู่ผลสแกนกับผู้ใช้
- **รายงาน Excel:** ส่งออกรายงานสรุปและรายละเอียดการสแกน
- **Supabase:** จัดเก็บข้อมูลผู้ใช้ ข้อมูลลายนิ้วมือ และประวัติการสแกน

## โครงสร้างโปรเจกต์

```text
fingerprint-attendance/
├── app.py              # Flask Web Application และ API
├── database.py         # จัดการการเชื่อมต่อ Supabase
├── report.py           # สร้างรายงาน Excel
├── scanner.py          # เชื่อมต่อเครื่อง ZKTeco ZK9500
├── requirements.txt    # รายการ Python dependencies
├── templates/          # HTML templates (Jinja2)
└── static/             # CSS และ JavaScript
```

## สิ่งที่ต้องเตรียม

- Python เวอร์ชันที่รองรับ SDK ของเครื่องสแกน
- เครื่องสแกนลายนิ้วมือ ZKTeco ZK9500
- Driver และ SDK ของ ZKTeco
- โปรเจกต์ Supabase และตารางที่ตรงกับโค้ดใน `database.py`
- ค่า URL และ API key สำหรับเชื่อมต่อ Supabase

## วิธีติดตั้ง

เปิด PowerShell ในโฟลเดอร์โปรเจกต์

```powershell
cd fingerprint-attendance
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

ตรวจสอบว่าเครื่องสแกนเชื่อมต่อผ่าน USB และติดตั้ง Driver/SDK เรียบร้อยแล้ว

## การตั้งค่าก่อนใช้งาน

1. ตั้งค่าตัวแปร Environment สำหรับเชื่อมต่อ Supabase ตามที่ `database.py` กำหนด
2. ตรวจสอบตารางและคอลัมน์ใน Supabase ให้ตรงกับโค้ด
3. เปลี่ยน `app.secret_key` ใน `app.py` เป็นค่าที่คาดเดาได้ยาก
4. ตรวจสอบ URL ของ API ใน `scanner.py` โดยค่าเริ่มต้นใช้ `http://127.0.0.1:5000`

**ข้อควรระวัง:** ห้ามเผยแพร่ Supabase secret/service-role key หรือ `app.secret_key` ลง GitHub

## วิธีรันระบบ

ต้องเปิด Terminal 2 หน้าต่าง และเปิดใช้งาน virtual environment ในทั้งสองหน้าต่าง

### 1. รันเว็บแอป

```powershell
uvicorn app:asgi_app --host 127.0.0.1 --port 5000
```

เปิดเบราว์เซอร์ที่:

- Dashboard: `http://127.0.0.1:5000/`
- จัดการผู้ใช้: `http://127.0.0.1:5000/users`
- รายงาน: `http://127.0.0.1:5000/reports`

ตรวจสอบชื่อ route จริงใน `app.py` หาก URL ของหน้าเว็บแตกต่างจากรายการนี้

### 2. รันเครื่องสแกน

```powershell
python scanner.py
```

เมื่อ SDK เชื่อมต่อกับ ZK9500 สำเร็จ โปรแกรมจะรอรับลายนิ้วมือ ระบุตัวตน และส่งผลไปยัง API ของเว็บแอป

หากต้องการตรวจสอบคำสั่งที่รองรับ ให้ใช้:

```powershell
python scanner.py --help
```

การลงทะเบียนลายนิ้วมือให้ทำตามขั้นตอนที่ระบบเวอร์ชันปัจจุบันกำหนด และตรวจสอบว่า `fingerprint_id` ถูกผูกกับผู้ใช้ที่ถูกต้อง

## ขั้นตอนการใช้งาน

1. เปิดเว็บแอปและตรวจสอบการเชื่อมต่อ Supabase
2. เพิ่มข้อมูลนักศึกษาหรือบุคลากรในหน้าจัดการผู้ใช้
3. ลงทะเบียนลายนิ้วมือผ่านขั้นตอนของระบบ
4. ตรวจสอบการจับคู่ลายนิ้วมือกับผู้ใช้
5. เปิด `scanner.py` ค้างไว้
6. ให้ผู้ใช้วางนิ้วบนเครื่อง ZK9500 เพื่อเช็กชื่อ
7. ตรวจสอบประวัติที่ Dashboard
8. เลือกช่วงวันที่ในหน้ารายงานและดาวน์โหลดไฟล์ Excel

## API สำคัญ

| Method | Endpoint | รายละเอียด |
|---|---|---|
| POST | `/api/scan` | รับผลการสแกนและบันทึกประวัติ |
| GET | `/api/scans/recent` | ดึงรายการสแกนล่าสุด |
| GET | `/reports/export` | ส่งออกรายงาน Excel |

ตรวจสอบ `app.py` เพื่อดูรายละเอียด request body และพารามิเตอร์ที่แต่ละ API ต้องการ

## การแก้ปัญหาเบื้องต้น

- **ไม่พบเครื่องสแกน:** ตรวจสอบ USB, Driver และ SDK
- **เริ่ม SDK ไม่สำเร็จ:** ตรวจสอบ DLL และความเข้ากันได้ของ Python กับ SDK
- **สแกนแล้วไม่พบผู้ใช้:** ตรวจสอบการลงทะเบียนและค่า `fingerprint_id`
- **ส่งข้อมูลเข้าเว็บไม่ได้:** ตรวจสอบว่าเว็บแอปทำงานอยู่และ URL ใน `scanner.py` ถูกต้อง
- **เชื่อมต่อ Supabase ไม่ได้:** ตรวจสอบ URL, key, environment variables และสิทธิ์เข้าถึงตาราง
- **ดาวน์โหลด Excel ไม่ได้:** ตรวจสอบช่วงวันที่และข้อความ error ใน Terminal

## ความปลอดภัยและ PDPA

- ข้อมูลลายนิ้วมือเป็นข้อมูลชีวมิติที่มีความอ่อนไหว ต้องจัดการตามนโยบาย PDPA ของมหาวิทยาลัย
- กำหนดวัตถุประสงค์ ฐานกฎหมาย ระยะเวลาเก็บรักษา และแนวทางลบข้อมูลให้ชัดเจน
- ควรเพิ่มระบบ Login และกำหนดสิทธิ์ผู้ดูแลก่อนใช้งานจริง
- จำกัดการเข้าถึง API และไม่เปิดระบบจัดการผู้ใช้หรือข้อมูลลายนิ้วมือสู่อินเทอร์เน็ตโดยไม่มีมาตรการรักษาความปลอดภัย
- ไม่ควรบันทึก template ลายนิ้วมือหรือข้อมูลชีวมิติลง log โดยไม่จำเป็น
- เก็บ secret และ API keys ใน Environment Variables หรือระบบจัดการความลับที่เหมาะสม
